# Interactive change

Use the namespaced skills in a Claude Code session:

```text
/parallax-claudecode:check-in ambiguity LOW: the request names the API and expected behavior.
/parallax-claudecode:plan Add validation to the profile update endpoint.
/parallax-claudecode:build Implement the accepted profile-validation plan.
/parallax-claudecode:trace export
```

Check-ins must cite observations from the repository. The first mutation remains blocked until ambiguity, invariants, and gate evidence are persisted in order.
