# Long-horizon goal

```text
/parallax-claudecode:horizon Migrate the service from ad-hoc API keys to rotating scoped tokens. Preserve compatibility for one release, add migration documentation, and prove rollback and expiry behavior with integration tests.
```

A good Horizon run persists research, decomposes independently verifiable features, uses Hyperplan for security and migration risk, applies full Parallax protocol to mutations, evaluates actual test output, and completes with a broad audit. Credential or deployment authorization is an external blocker; ordinary library and naming choices are not.
