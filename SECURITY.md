# Security Policy

## Supported versions

Security fixes are applied to the latest published release.

| Version | Supported |
|---|---|
| 0.1.x | Yes |
| Earlier | No |

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/Master0fFate/parallax-claudecode/security/advisories/new) and include:

- the affected version and platform;
- the trust boundary or component involved;
- minimal reproduction steps;
- realistic impact;
- any suggested mitigation.

Reports involving hook bypasses, command execution, path traversal, state corruption, lock races, secret exposure, or forged verification evidence are especially useful. You should receive an initial response within seven days. Confirmed issues will be coordinated privately until a fix and release are available.

Only test repositories and systems you own or are authorized to assess.
